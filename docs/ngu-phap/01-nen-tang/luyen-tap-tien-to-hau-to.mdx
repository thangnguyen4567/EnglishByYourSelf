# Luyện tập từ loại qua tiền tố & hậu tố

:::info[Trang luyện tập]
Trang này tóm tắt cách **phân biệt danh từ (n), động từ (v), tính từ (adj), trạng từ (adv)** dựa vào **hậu tố, tiền tố và vị trí**,
rồi cho bạn **45 câu luyện tập** theo 3 cấp độ. Lý thuyết đầy đủ xem ở [G01a · Từ loại](/docs/ngu-phap/g01-tu-loai).
:::

## 1. Bảng hậu tố – nhìn đuôi đoán từ loại

| Từ loại | Hậu tố | Ví dụ |
|---|---|---|
| **Danh từ** (vật, khái niệm) | -tion / -sion, -ment, -ness, -ity, -ance / -ence, -ship, -hood, -dom, -th, -ism | information, development, happiness, ability, difference, friendship, childhood, freedom, growth, tourism |
| **Danh từ** (người) | -er / -or, -ist, -ant / -ent, -ee, -ian | teacher, actor, scientist, assistant, student, employee, musician |
| **Động từ** | -ize / -ise, -ify, -en, -ate | modernize, simplify, strengthen, activate |
| **Tính từ** | -ful, -less, -ous, -ive, -able / -ible, -al, -ic, -y, -ish, -ent / -ant, -ed / -ing | useful, careless, dangerous, active, comfortable, emotional, economic, sunny, childish, different, bored / boring |
| **Trạng từ** | tính từ + -ly | quickly, carefully, extremely, luckily |

:::warning[3 bẫy hay gặp]
- **-ly nhưng là tính từ:** *friendly, lovely, lonely, lively, costly, likely, daily, weekly* → muốn làm trạng từ phải nói *in a friendly way*.
- **Không có -ly vẫn là trạng từ:** *fast, hard, late, early, well* (*hardly, lately* mang nghĩa khác hẳn).
- **-ed / -ing là tính từ:** người cảm thấy → *-ed* (*I'm bored*); vật gây ra cảm xúc → *-ing* (*a boring film*).
:::

## 2. Tiền tố – đổi nghĩa, hiếm khi đổi từ loại

| Tác dụng | Tiền tố | Ví dụ |
|---|---|---|
| Phủ định (giữ nguyên từ loại) | un-, in-, im- (trước b/m/p), il- (trước l), ir- (trước r), dis-, non- | unhappy, incorrect, impossible, illegal, irregular, dislike, non-stop |
| Sai / quá / dưới mức / lại | mis-, over-, under-, re- | misunderstand, overwork, underpaid, rewrite |
| **Đổi sang động từ** | en- / em-, be-, out- | danger → **endanger**, courage → **encourage**, large → **enlarge**, power → **empower**, friend → **befriend**, number → **outnumber** |
| **Tạo tính từ đứng sau be** | a- | **asleep, awake, alive, afraid** – ~~an asleep baby~~ → *a sleeping baby* |

Một từ có thể có **cả tiền tố lẫn hậu tố** – hãy tách từng lớp: **un** + believ + **able** (adj) + **ly** (adv) → *unbelievably*.

## 3. Vị trí trong câu – dấu hiệu chắc chắn nhất

| Đứng ngay trước chỗ trống | Cần | Ví dụ |
|---|---|---|
| a / an / the / my / his / sở hữu cách 's / tính từ | **Danh từ** | the **construction** of…, her **determination**, a big **difference** |
| to / can / will / must / should / don't | **Động từ** nguyên mẫu | need to **simplify**, can **strengthen** |
| be / seem / look / feel / become, very / so / too | **Tính từ** | He is **nervous**. very **useful** |
| Trước danh từ | **Tính từ** | an **emotional** speech |
| Sau động từ thường (+ tân ngữ), trước tính từ, đầu câu + dấu phẩy | **Trạng từ** | explained it **clearly**, **extremely** boring, **Luckily**, … |

:::tip[Quy trình 3 bước]
1. **Vị trí** → cần từ loại gì?
2. **Hậu tố** của các phương án → loại bỏ từ sai loại.
3. **Nghĩa / tiền tố** (phủ định? *-ed* hay *-ing*?) → chọn đáp án hợp ngữ cảnh.
:::

## 4. Bài luyện tập theo cấp độ (45 câu)

- **Dễ:** nhìn hậu tố, chọn đúng từ loại.
- **Trung bình:** điền dạng đúng của từ vào câu, dựa vào vị trí.
- **Khó:** tiền tố phủ định, tiền tố đổi từ loại, *-ed / -ing*, bẫy *-ly*, tìm lỗi sai.

Đạt ≥ 80% ở một cấp rồi mới chuyển sang cấp tiếp theo. Điểm cao nhất được lưu trên tab.
